Lab Measurement & Precision Practice

Read the scale • use the correct reference point • report supported precision

Science skills practice

Measure what the instrument actually allows you to know.

You will read two graduated cylinders, a triple-beam balance, and an Erlenmeyer flask. The goal is not just to get a number. You will interpret graduations, choose the correct reading point, use the correct unit, and report only the precision supported by the instrument.

1. Read the scale firstDetermine what the smallest marked graduation represents.
2. Use the correct reading pointFor the water-like liquids in this practice, read the bottom of the concave meniscus at eye level.
3. Record supported precisionFor a graduated cylinder, record the certain digits and estimate one additional digit beyond the smallest graduation.
4. Choose appropriate equipmentMore digits do not make a measurement more accurate if the instrument cannot support them.
Triple-beam balance: read each rider at the scale provided and add the beam values. In this practice the front beam is marked every 0.1 g, so you read the certain digits shown and estimate one additional digit, recording the final mass to 0.01 g.

Practice sequence

  1. 100 mL graduated cylinder
  2. 10 mL graduated cylinder
  3. Triple-beam balance
  4. Equipment judgment: Erlenmeyer flask

Each problem includes an enlarged view, a text-equivalent description, and keyboard-operable controls. Feedback uses words and symbols rather than color alone.
